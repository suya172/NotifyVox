NotifyVox v{{VERSION}} (Windows x64) セットアップガイド
======================================================

NotifyVox をダウンロードいただきありがとうございます。
NotifyVox は Windows の通知をリアルタイムに取得し、VOICEVOX で読み上げる常駐アプリです。

■ 1. 事前準備 (VOICEVOX の導入)
NotifyVox の音声合成には「VOICEVOX (バージョン 0.26.0 以降)」が必要です。
まだお持ちでない場合は、公式サイトからインストールして起動しておいてください。
  公式サイト: https://voicevox.hiroshiba.jp/

■ 2. インストール手順
1) ダウンロードした ZIP ファイルを右クリックし、「すべて展開」でフォルダに解凍します。
2) 展開されたフォルダ内の「Install.cmd」をダブルクリックして実行します。
   ※ Windows SmartScreen（「Windows によって PC が保護されました」）が表示された場合は、
      「詳細情報」→「実行」をクリックしてください。
   ※ 初回のみ、署名証明書（NotifyVox.cer）を「信頼されたユーザー」へ登録するため
      管理者権限の確認画面（UAC）が表示されますので「はい」を選択してください。
3) インストールが完了すると自動的に NotifyVox が起動し、タスクトレイに常駐します。

■ 3. 初回起動時の設定
1) 初回起動時、Windows の「通知へのアクセス」許可がまだ OFF の場合は設定画面に案内バナーが
   表示されます。「Windows 設定を開く」ボタンから NotifyVox の通知アクセスを ON にしてください。
2) 「アプリ一覧」タブで、通知を読み上げたいアプリを ON に切り替えると読み上げが開始されます。

■ 4. アップデート手順
新しいバージョンの ZIP を展開し、同様に「Install.cmd」（または .msix ファイル）を実行してください。
同じ署名証明書が使われているため、2回目以降は証明書の再登録なしでそのまま上書き更新され、
設定内容も引き継がれます。

■ 5. アンインストール手順
- アプリと自己署名証明書の両方を綺麗に削除したい場合:
  本フォルダ内の「Uninstall.cmd」をダブルクリックして実行してください。
- アプリ本体のみ削除したい場合:
  Windows の「設定」>「アプリ」>「インストールされているアプリ」から「NotifyVox」を
  アンインストールすることもできます。
